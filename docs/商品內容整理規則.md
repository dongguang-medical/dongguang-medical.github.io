# 商品內容整理規則

清洗蝦皮匯出資料時的操作手冊。

---

## 〇、最高原則：不得捏造

**只能對現有文字做「搬移欄位」與「刪除冗餘」兩種動作。**

- 不得憑空撰寫任何商品描述、用途說明、特色文案
- 不得推測或補齊缺漏的規格數值
- 內文清空後就是空的，不要填東西進去
- 蝦皮沒寫的資訊，網站就沒有

---

## 一、匯入方式

一律以蝦皮原始 xlsx 為輸入，一次算到位。**不得對已清洗的結果再套一輪清洗**
（誤刪救不回，前一輪的副作用會變成下一輪的輸入）。

```
python3 scripts/import_shopee.py --sales <銷售資訊.xlsx> \
                                 --media <媒體資訊.xlsx> \
                                 --basic <基本資訊.xlsx> [--dry-run]
```

匯出：賣家中心 → 商品 → 批次工具 → 批次更新 → 選類別 → 下載。

| 匯出類別 | 提供 |
|---|---|
| 銷售資訊 | 每規格一列，含價格 → `price` / `variants` |
| 媒體資訊 | 每商品一列，含規格名稱 → `variant_label` |
| 基本資訊 | 每商品一列，含商品描述 → 內文與 `regulatory` |

比對只用 `shopee_url` 裡的商品 ID 對匯出檔的商品 ID，不做名稱模糊比對。

---

## 二、資料放哪裡

| 內容 | 去處 |
|---|---|
| 固定屬性：材質、尺寸、數量、產地、滅菌狀態、適用機型、保存期限、主要成分 | `specs` |
| 可選規格與各自價格 | `variants` |
| 法定標示（見第四節） | `regulatory` |
| 使用方式、注意事項、款式差異 | 內文 |

`specs` 的標籤跟著商品走，不做全站正規化。

---

## 三、商品頁版面

順序：**商品規格 → 商品說明 → 法定標示**。

全頁只出現一張「商品規格」卡，`variants` 併入其中，分三種形態：

**A. 可選規格全部同價**——不顯示價格欄，選項收成一列。

```
尺寸    M(單支)、L(單支)
長      27.5 cm
產地    台灣製造
```

**B. 可選規格不同價**——兩欄小表排在固定屬性之前，細線分隔，同一張卡內。

```
尺寸            價格
S            NT$799
M            NT$899
────────────────────
材質    熱可塑性彈性體
直徑    S 15／M 20／L 24 公分
```

**C. 無可選規格**——單純屬性表。

S/M/L 各自的尺寸數值併成一列，不拆成多列，不塞進規格標籤。

## 四、法定標示（`regulatory`）

前台與後台標題皆為「法定標示」。

### 收錄五項，標籤固定

```
許可證字號
許可證品名
持證藥商
製造廠
製造廠地址
```

蝦皮原始資料同一件事有多種寫法（醫療器材許可證所載核准字號／醫療器材許可證
核准字號／許可證核准字號／醫療器材許可證字號/登錄字號／醫療器材許可證字號／
許可證字號），一律歸到上表的固定名稱。持證藥商同理：醫療器材許可證所載藥商
名稱／許可證所有人／進口藥商名稱／廠商名稱，都是持證藥商。

只寫了地址而沒寫名稱者（如「製造廠名稱及地址：新北市…」），只填製造廠地址，
不把地址反推成名稱。

**不新增項目**，除非在實際的法定標示段落中出現上表未涵蓋的項目，再個別討論。

### 不收錄

- **原產地、主要成分**——歸 `specs`（產地、材質）
- **生產/製造商電話、販售規格**——電話不需要，販售規格歸 `specs`
- **持證藥商／進口藥商的地址**——只留名稱，地址欄只給製造廠用
- **店家自己的藥商資訊**——由程式生成，見下
- **罐頭值**——「產品製造日期：標示於包裝上」「有效期間或保存期限：標示於包裝上」

### 店家藥商資訊由程式輸出

接在每個商品的法定標示下方，資料存一份常數，不逐項寫進 frontmatter：

```
販售藥商      東光儀器有限公司
藥商地址      台南市東區崇德路 677、679 號
藥商許可執照   南市衛藥販字第6221011898號
諮詢專線      0911465368
消費者使用前應詳閱產品說明書。
```

### 非管制品留空

無許可證的商品（碗盤、牙刷、保健食品等）欄位留空，前台不顯示此區塊。

## 五、內文刪除清單

- **平台與物流**：7-11／全家／萊爾富／超商／宅配／出貨／運費／一單最多／
  一張單限下一件／網拍／下標／聊聊／私訊／賣場／評價／面交／退換貨猶豫期
- **政府查詢連結區塊**：相關查詢連結／※設立許可證明文件／查詢連結：／
  整段 FDA 網址與查詢路徑
- **關鍵字標籤**：`#透明手套` 這類。行首的 `#` 未清除會被誤判為 Markdown 標題
- **重複貼多次的同一句**
- **固定日期**：如「製造日期：2012/06/01」，刪除或改「詳見包裝標示」
- **排版殘骸**：`:-材質` 殘留冒號、`*****規格尺寸*****` 星號裝飾、
  `規　　格` 異常空白、`子母行內徑`（應為「型」）等錯字
- **安全警語**：「提醒您：」「使用前請詳閱使用說明書」等，改由程式統一輸出一次

### 規格名稱裡的訂購限制

蝦皮賣家常把每筆訂單的數量上限寫進規格名稱，一律移除：

```
XL(一單限2包)      → XL
醫强(一單限8瓶)     → 醫强
12F(1單限2包)      → 12F
```

那是蝦皮的出貨限制，本站不出貨。移除後若造成排序錯亂（如 XL、M、L），
依尺寸重排。

移除後若規格名稱與某個規格列重複（例如都叫「尺寸」），把數值併進規格
名稱、刪掉那一列——`M（20-27吋・60-85CM）` 這種寫法。

注意分辨：「加購刷子1支」描述的是商品組合內容，不是訂購限制，保留。

## 六、一頁只放一個品牌

**不同品牌必須拆成不同商品，即使品名是中性的。**

蝦皮常把同款不同牌的東西併在一則賣場賣，但那是兩個商品：規格不同、
許可證不同、價格也不同。併在一頁會讓規格表和法定標示都指涉不明。

判準是**品牌**，不是品名寫法：

- `supplies-45` 品名寫「優美 UMED 採血針」卻同時賣優美與明傑 → 要拆
- `misc-32` 品名寫中性的「木製壓舌板」，賣豐全與瑞玉 → **一樣要拆**

拆分前先確認蝦皮原文對每個品牌都有足夠資訊（各自的許可證、規格）。
資訊不足者維持現狀，法定標示把每張許可證用「／」並列，並在括號標明是哪個品牌
或哪個品項。

圖片歸位靠蝦皮的商品照：包裝標籤照上印的許可證字號就是歸屬依據。
分不出來的（例如兩張都是無標示的產品照）兩頁各放一份，不要猜。
拆出來的品牌若一張圖都沒有，新頁 `published: false`——本站沒有圖就不上架。

---

## 七、不動的東西

- **行銷語氣**：即使是蝦皮風格用語也保留原文，不改寫
- **既有 `specs`**：與蝦皮原文衝突時**以蝦皮為準**；蝦皮沒有的視為未驗證
  資料，不得當成事實保留

---

## 八、技術限制

**frontmatter 寫入**（`parse_frontmatter`）：

- 值裡的「空白＋`#`」之後會被當註解截斷
- 引號必須成對
- 以上由 `import_shopee.py` 的 `yaml_value()` 處理
- 多行文字（`regulatory`）用 YAML 區塊字串 `|`

**Markdown 轉換**（`md_to_html`）：

- `#` 開頭的區塊只輸出標題，同段其餘內容會被整段丟棄
- 因此段落標題轉 `###` 時必須前後補空行，使標題自成一個區塊
