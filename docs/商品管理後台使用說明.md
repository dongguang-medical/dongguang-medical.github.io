# 商品管理後台使用說明

## 一、如何打開後台

1. 打開瀏覽器（Chrome、Safari、Edge 都可以）。
2. 在網址列輸入：

   ```
   https://dongguang-medical.github.io/admin/
   ```

3. 建議把這個網址「加入書籤 / 加到主畫面」，之後點一下就能進來。

---

## 二、如何登入

1. 進入後台後，點畫面上的「**Sign in with GitHub**（使用 GitHub 登入）」按鈕。
2. 輸入管理者幫你申請好的帳號和密碼。
   - 帳號密碼請向網站管理者索取，並好好保存。
   - 第一次登入時，畫面可能會跳出一個英文的授權視窗，點綠色的「**Authorize**（授權）」按鈕即可。
3. 登入成功後，就會看到「商品」列表。

---

## 三、新增商品

1. 進入後台，點左邊的「**商品**」。
2. 點右上角的「**新增**」按鈕（可能顯示為「Create」或「＋」）。
3. 依序填寫欄位：
   - **商品名稱**：一定要填，例如「鋁合金四輪助行車」。
   - **商品分類**：一定要選。下拉選單裡是「主分類 › 子分類」的組合（例如「行動輔具 › 輪椅」），
     可以直接打字篩選——輸入「氣墊」就會只剩氣墊床。
   - **售價**：可以不填。**只要填數字就好**，例如 `3500`——不用打「NT$」，也不用打逗號，
     網站上會自動顯示成 `NT$3,500`。**不填的話，網站上會顯示「歡迎洽詢」**，
     所以價格常變動的商品可以留空。
   - **提供方式**：可複選，預設是「門市洽詢」。
     勾「**線上選購**」表示蝦皮賣場有賣，**請一併填下面的「蝦皮商品連結」**，
     商品頁才會出現「到蝦皮下單」按鈕。
   - **可租賃**：開關。打開後商品會出現在網站的租賃專區，商品卡也會顯示「可租賃」標記。
   - **租金**：只有可租賃的商品要填，例如 `800/月`、`1500/季`（會照你填的原樣顯示）。
   - **蝦皮商品連結**：勾了「網購」才要填。到蝦皮賣場打開該商品，把網址列的網址整段貼進來
     （要以 `https://shopee.tw/` 開頭）。
   - **品牌**：可以不填。只能從清單挑，找不到的話要先到左邊「品牌」新增一筆。
   - **標籤**：可以不填。例如「保固一年」、「台灣製造」，一次加一個，可以加好幾個。
     （補助與租賃已經有各自的欄位，不用在標籤重複填。）
   - **規格**：可以不填。一列填一項，左邊填項目（例如「承重」），右邊填數值（例如「100 公斤」）。
   - **商品照片**：點「新增照片」上傳，**第一張會當作封面**，照片的順序可以用拖曳調整。
   - **上架顯示**：新商品預設是開的，不用動它。
   - **商品說明**：想寫多少就寫多少，換行、條列都可以。
4. 都填好之後，點右上角的「**儲存**」（Save）。
5. **存檔後網站不會馬上更新**，通常要等 1～3 分鐘，網站才會出現新商品。等幾分鐘後到網站上重新整理看看即可，不用重複儲存。

---

## 四、修改商品

1. 在「商品」列表中，點你要改的那個商品。
2. 直接修改要改的欄位。
3. 點右上角「**儲存**」。
4. 一樣等 1～3 分鐘，網站就會更新。

---

## 五、下架商品（暫時不賣，但以後可能再賣）

不需要刪除商品，只要：

1. 點進那個商品。
2. 把「**上架顯示**」的開關關掉。
3. 點「**儲存**」。

商品就不會出現在網站上了。以後要再賣，把開關打開、再儲存一次就好。

> 如果確定以後都不會再賣，也可以在商品列表勾選該商品後點「刪除」。刪掉就找不回來了，不確定的話請用「下架」就好。

---

## 六、上傳照片的注意事項

- **手機直接拍就可以**，不需要專業相機。光線亮一點、背景乾淨一點，拍出來效果就不錯。
- **建議一張照片 500KB 以內**。太大的照片會讓網頁變慢。
  - 手機拍的原始照片通常太大，可以先用手機內建的編輯功能裁切，或用 LINE 傳給自己一次（LINE 會自動縮小），再存下來上傳。
- **iPhone 使用者請注意**：iPhone 預設拍出來的是 HEIC 格式，網頁可能無法顯示。請先做一次這個設定（設定一次就好）：
  1. 打開 iPhone 的「**設定**」
  2. 點「**相機**」
  3. 點「**格式**」
  4. 選「**最相容**」

  這樣拍出來的照片就是 JPG 格式，網頁一定可以用。
- 每個商品可以放多張照片，**第一張是封面**，請把最好看的那張放第一張。

## 七、常見問題

**Q：我存檔了，可是網站上看不到？**
A：請等 1～3 分鐘再重新整理網頁。如果超過 10 分鐘還是沒有，請聯絡網站管理者。

**Q：我不小心改錯了怎麼辦？**
A：別擔心，所有修改都有留紀錄，網站管理者可以幫你救回來。有問題先聯絡管理者，不要自己亂試。

**Q：可以用手機操作後台嗎？**
A：可以，用手機瀏覽器打開同一個網址即可，適合臨時修改。但欄位比較多的時候，用電腦操作會比較舒服。

**Q：登入不進去？**
A：先確認帳號密碼有沒有打錯（注意大小寫）。還是不行的話，聯絡網站管理者。
